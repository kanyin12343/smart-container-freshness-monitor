
# Smart Container — Freshness Monitoring (Ethylene + RGB LED)

## Overview
Smart Container is a simple embedded prototype that monitors produce freshness using an ethylene gas sensor and displays status using an RGB LED.

## How it works
- The sensor output is read by an Arduino (analog input).
- The reading is compared to thresholds.
- The RGB LED indicates freshness level:
- 🟢 Fresh
- 🔴 Spoiled

## Repo contents
- `firmware/` — Arduino code
- `images/` — prototype photo(s)

## Hardware used
- Arduino (Uno or compatible)
- Ethylene gas sensor module
- RGB LED + resistors
- Breadboard / jumper wires
